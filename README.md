# RFID-Based Student Attendance System

## Project Overview
This is an academic team project using Arduino Uno, RFID technology, and an LCD display for student identification and attendance-related applications.

## Components
- Arduino Uno
- RFID Reader (model to be confirmed)
- RFID Card
- LCD Display
- Connecting Wires

## Working Principle
1. The RFID reader reads the RFID card.
2. Arduino Uno processes the card information.
3. The LCD displays a message based on the program.

## Learning Outcomes
- Basic understanding of RFID technology
- Arduino hardware interfacing
- LCD display interfacing
- Teamwork and project development

## Project Type
Academic Team Project
